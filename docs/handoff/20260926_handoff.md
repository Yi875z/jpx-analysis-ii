# 2026-09-26 引き継ぎ — レポート生成モデルを Claude Opus 5.5 へ

ブランチ `feat/opus-5-5`（未push。push すると次の木曜の定期実行から Opus 5.5 になる）。

## 何をしたか

- `agents/report_agent.py`: 既定モデルを `claude-opus-5-5` に。effort を明示（`DEFAULT_EFFORT = "high"`、
  `CLAUDE_EFFORT` で上書き可）。安全分類器に拒否されたら（`stop_reason == "refusal"`）`claude-opus-5` で
  1回だけ書き直し、それでも拒否なら例外にする（空のレポートを公開前チェックとメールへ流さない）。
  週次・月次の2か所の呼び出しを `_stream_report` に集約。
- `.github/workflows/weekly_fetch.yml`: `CLAUDE_MODEL: claude-opus-5-5`（こちらがコードの既定より優先される）。
- `scripts/send_summary_mail.py`: メールのモデル表示名に Opus 5.5 を追加。
- `tests/test_model_config.py`（新規5件）。

## なぜ（Opus 5 → 5.5 で変わる点）

- effort の既定が high → **medium** に下がる。指定していなかったので、モデル名だけ替えると黙って浅くなる。
- 思考を止める設定（`disabled` / `budget_tokens`）は 400 になる。本コードは `adaptive` なので影響なし。
- ツールの強制指定・computer use は使っていないので、残りの破壊的変更は該当しない。
- 安全分類器が広がる（bio・reasoning_extraction が追加）。拒否は HTTP 200 の `refusal` で来るため、
  検知しないと本文が空になる。
- 単価は Opus 5 の 8割（$4 / $20 per MTok）。
